# Pre-Legal Document Generator

A SaaS-based web application for creating pre-legal documents using ready-made templates.

## About

Pre-Legal Document Generator allows users to select a document template, enter the required information, and generate professional documents in PDF or DOCX format.

## Features

* User authentication
* Document templates
* Dynamic document creation
* PDF & DOCX generation
* Document history
* Secure user data
* Responsive dark-themed UI
* Free to use

## Tech Stack

* Next.js
* TypeScript
* Tailwind CSS
* Supabase
* PostgreSQL
* Docker
* Vercel

## Deployment

The application is deployed on **Vercel** with **Supabase** used for authentication and database services.

## Purpose

This project was developed as an academic SaaS project to demonstrate modern web development, authentication, database integration, document generation, Docker implementation, and cloud deployment.

## Disclaimer

This tool is intended for pre-legal document drafting and educational purposes. Generated documents should be reviewed by a qualified legal professional when necessary.
